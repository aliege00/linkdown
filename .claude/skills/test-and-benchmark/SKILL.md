# test-and-benchmark

Uygulamanin farkli senaryolar altinda kararli calisip calismadigini test et.

## Steps

1. Test ortamini ve ornek URL'leri hazirla.
2. Farkli medya ve baglanti senaryolarini yürüt.
3. Kaynak kullanımını (RAM/CPU) analiz et.
4. Sonuclari raporla.
