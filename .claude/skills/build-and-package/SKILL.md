# build-and-package

Uygulama kodunu derle, bagimliliklari pakete dahil et ve yayin dosyasini olustur.

## Steps

1. Derleme oncesi kontrolleri yap.
2. Derleme komutunu yürüt.
3. Çıktı dosyasini ve bagimliliklari dogrula.
4. Sürüm notlarini hazirla.
